GS STUDIOS PRODUCTION CLOUD CONTROL

1. Is complete folder ko Vercel/Netlify par upload karo.
2. Streamer page: /index.html
3. Tumhara private admin: /admin.html
4. Har overlay ka dedicated manager admin page se open hota hai.
5. Same PC/browser par bina setup local live control chalega.
6. Streamer alag PC par ho to /control/setup.html me Firebase Realtime Database Web config paste karo, Room ID set karo, aur generated MAIN PAGE link streamer ko bhejo.
7. OBS Browser Source me generated overlay URL use karo.

IMPORTANT: admin.html ka link public streamer ko mat bhejna. Firebase database rules ko event ke baad secure karna.
